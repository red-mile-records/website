# Red Mile Set Bible

Source for the studio lighting and set guide, published at
https://claude.ai/artifact/4xRxXwSDcz7S2bwNcxczri

One self-contained page (`index.html`) with five stages: Plan, Buy, Place, Camera, Run.

- **Buy**: three tiers (Tier 1 fixed 5600K, Tiers 2 and 3 bi-colour) with per-role mix and match.
  Prices are CAD before GST from the Gear Scout hunt `studio-lighting-2026-10` (re-checked Oct 31 2026).
- **Place**: to-scale top-down plan of the 10x10 ft room (armchair left of frame, couch centre and right).
- **Camera**: house standard at 29.97 (Sony NTSC "30p"), 1080p switched, 4K internal on the ZV-E10 II singles.
- **Run**: rig-day protocol, Rig Log, pre-show checklist, background scenes, fixes.

Shared state lives in the artifact's database, not in this file:
`build/current` (selected options + camera Kelvin), `status/<productId>`, `checks/{rigday,preshow}`, `riglog/<fieldId>`.

To update: edit `index.html` and republish it to the same artifact URL.
